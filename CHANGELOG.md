# Changelog

All notable changes are documented here. This project follows
[Semantic Versioning](https://semver.org/) and the structure recommended by
[Keep a Changelog](https://keepachangelog.com/).

## [Unreleased]

### Added

- Public contribution, security, support, issue, and pull-request guidance.
- GitHub Actions for CI and tagged GitHub releases.
- Automated dependency update configuration.

## [2.0.0] - 2026-06-28

### Added

- Interactive and non-interactive project generation.
- Composable `general`, `tabular`, `deep-learning`, `genai`, and `hf` profiles.
- uv, Conda, and combined environment workflows with Jupyter guidance.
- Optional MLflow and DVC integrations.
- Central dependency catalog, generated CI, tests, Ruff, and pre-commit configuration.
- Safe dry runs, input validation, and non-destructive regeneration.
