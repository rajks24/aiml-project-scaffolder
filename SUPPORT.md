# Support

## Usage help

Start with:

- [README](README.md)
- [Interactive Mode Guide](docs/INTERACTIVE_GUIDE.md)
- [Profile Guide](docs/PROFILE_GUIDE.md)
- [Environment and Jupyter Guide](docs/ENVIRONMENTS.md)

Search existing [issues](https://github.com/rajks24/aiml-project-scaffolder/issues) before opening a
new one. For setup questions, include the command used, operating system, Python version,
environment manager, selected profiles, and complete error output with secrets removed.

## Bugs and feature requests

Use the repository issue forms. Minimal reproducible examples and a `--dry-run` file listing are
especially helpful for generation problems.

## Security

Do not request security help publicly when details could expose users. Follow
[SECURITY.md](SECURITY.md).

## Expectations

This is a community-maintained open-source project. Support is best-effort, response times are not
guaranteed, and maintainers may redirect environment-specific package problems to the relevant
upstream project.
